Personal Projects

Chip-8 — Hardware Emulator (C++)

A complete emulator for the Chip-8 virtual machine, written to work through CPU, memory, and timing behavior at the instruction level.

  • Implements the full 35-instruction set, decoding opcodes with bitmasking and dispatching through function-pointer tables and sub-tables rather than a monolithic switch.
  • Runs the CPU and the hardware timers on independent fixed-rate loops (960 Hz and 60 Hz), keeping execution rate decoupled from frame rate.
  • Models the memory map, stack, register file, keypad input, and framebuffer directly, uploading the display to the GPU each frame.

MAGE — C++ Framework over the Vulkan API

A framework built from scratch on Vulkan, a low-level explicit graphics API where resource lifetime, synchronization, and memory are the caller's responsibility.

  • Wraps device setup, swapchain recreation, command buffers, descriptor pools, and texture uploads behind small RAII classes, making resource cleanup deterministic and leak-free.
  • Designed as a reusable library with builder-style configuration, then validated against a real workload by using it as the display backend for the Chip-8 emulator above.
  • Handles GPU memory allocation, buffer/image layout transitions, and per-frame data via uniform buffers and push constants.

PongGL — OpenGL Renderer (C++)

A from-scratch 2D application built directly on OpenGL with no engine or framework — my entry point into graphics and real-time programming. Archived as-is.

  • Hand-written render loop, vertex buffer setup, and shader pipeline.
  • Manual AABB collision detection and physics integration.
